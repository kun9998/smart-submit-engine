# 功能介绍

管理后台登录后，大致会看到这些能力（不同版本菜单名可能略有差异）。

## 总览 / 仪表盘

看引擎是否在跑、队列是否正常、今天大概处理了多少单。  
先看这里，能快速判断「是不是挂了」。

## 货源 / 平台规则

核心配置区：

- 每个货源对应怎么提交（接口地址、字段映射、脚本规则等）
- 可用规则编辑、试跑、校验
- 部分环境支持 AI 辅助生成/转换规则（需在系统设置里配置 AI 密钥）

没有配好规则，订单即使入队也不会正确提交。

## 订单 / 队列相关

- 待提交订单会进 Redis 队列
- 支持手动重新提交、看失败原因
- 有限流时，会按配置放慢提交速度，避免把上游打爆

## 系统设置

- **订单队列（Redis）**：地址、密码、库号
- **访问安全**：出站域名白名单、是否拦内网地址等
- **智能助手**：可选，给规则转换 / 运维分析用

本开源版没有「授权码」设置项。

## 系统监控

看进程、连接是否正常，方便排查卡顿、断库、断 Redis。

## 日志

提交失败、超时、异常会记下来。  
排查「某一单为什么没成功」时优先看日志。

## AI 运维（若开启）

根据日志和策略，给出简单分析或建议。  
需要先在设置里填可用的大模型接口。

## 个人中心

改登录密码、可选两步验证等账号安全设置。

## 系统升级

原版会连授权站检查更新。  
**本开源版已关闭在线升级**，请通过 Git 更新源码后自行编译替换。
