# 安装说明

用大白话讲：装好 MySQL、Redis，编译程序，打开网页点几下就行。

## 1. 环境检查

### MySQL

- 建议 5.7 / 8.0
- 准备 **两个数据库**（名字随意）：
  - **主站库**：已有订单表的那个（表前缀可在安装时填，默认类似 `love_learn`）
  - **插件库**：给本引擎用，空库即可，安装时会自动建表

同一台 MySQL、两个库名，完全可以。

### Redis

- 本机默认：`127.0.0.1:6379`
- 有密码就记下来，安装/设置里填写

### Go

```bash
go version
```

建议 1.22 及以上。本项目 `go.mod` 可能写了较新版本，按提示升级即可。

### Node.js（编译前端时需要）

```bash
node -v
npm -v
```

建议 Node 18+。

## 2. 配置文件

```bash
# Windows
copy config.example.yaml config.yaml

# Linux / macOS
cp config.example.yaml config.yaml
```

说明：

- **不要把填了真实密码的 `config.yaml` 上传到 GitHub**
- 第一次可以几乎不改，靠网页安装向导写入连接信息
- 管理端默认端口：`8090`（`admin.addr: ":8090"`）

## 3. 启动

在项目根目录：

```bash
go build -o tj.exe .
.\tj.exe
```

看到日志里出现启动成功后，浏览器打开：

```
http://127.0.0.1:8090
```

## 4. 网页安装向导

按步骤填：

1. 主站库主机、端口、账号、密码、库名、表前缀  
2. 插件库同上  
3. 管理员用户名、密码（至少 6 位）  

点「完成安装」。成功后用刚设的账号登录。

若提示「订单队列未启动」，多半是 Redis / 主站库还没连上，到「系统设置」里检查后重启程序。

## 5. 编译前端（可选）

仓库若已带 `admin-dist`，一般不用再编。自己改了 `web/` 时：

```bash
cd web
npm install
npx vite build
```

将 `web/dist` 整份复制为项目根目录的 `admin-dist`，然后重启后端。

Windows 也可用：

```bash
build-frontend.bat
```

## 6. 常见问题

**打不开 8090？**  
看防火墙、看 `config.yaml` 的 `admin.addr`，看端口是否被占用。

**安装失败：连不上数据库？**  
检查账号权限、库是否已创建、主机是否填 `127.0.0.1`（本机不要乱填公网 IP）。

**队列不跑订单？**  
确认：主站库有待提交订单、Redis 正常、货源/平台规则已配置。

**忘记管理员密码？**  
可在插件库的管理员表重置（表名一般带 `tj_` 前缀），或重新用空插件库安装（会丢插件侧配置，慎用）。

## 7. 生产环境小建议

- 改掉默认弱密码
- MySQL / Redis 不要对公网裸奔
- 定期备份主站库与插件库
- 用 systemd / NSSM / 计划任务保证进程挂了能拉起
