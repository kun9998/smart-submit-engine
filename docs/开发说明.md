# 开发说明

适合想改代码的人。目标：本地能改、能跑、能看效果。

## 后端（Go）

根目录就是 Go 模块（`module tj`）。

```bash
# 下载依赖
go mod tidy

# 直接跑（需已有 config.yaml）
go run .

# 或编译
go build -o tj.exe .
```

常用入口：

- `order_queue.go`：主程序 `main`、订单队列
- `admin_*.go`：管理后台 API
- `platform_rule*.go`：平台提交规则
- `ops_*.go`：运维 / 告警相关

改完后端一般只要重新 `go build` / `go run`。

## 前端（Vue）

代码在 `web/`：

```bash
cd web
npm install
npm run dev
```

开发服务器默认会代理到后端。后端请先在 `8090`（或你配置的端口）跑起来。

打包给后端嵌入/托管：

```bash
cd web
npx vite build
# 把 dist 同步到 ../admin-dist
```

## 两边一起开发（Windows）

仓库里有快捷脚本：

- `dev-backend.bat` — 跑后端
- `dev-frontend.bat` — 跑前端

先开后端，再开前端。

## 配置

本地只用 `config.yaml`（从 `config.example.yaml` 复制）。  
该文件已加入 `.gitignore`，避免把密码推上网。

## 本开源版注意点

- 已删除授权站相关代码（原 `auth.go` 等）
- 「在线升级」依赖授权站，本版不可用；更新请 `git pull` 后自行编译
- 后台登录、接口鉴权仍在，改管理 API 时别去掉登录校验

## 提交代码前

```bash
go build .
# 前端有改动时
cd web && npx vite build
```

确认没有把 `config.yaml`、真实密钥加进 Git。
